## Data Analysis and Figure Generation for "Sediment Trap Deployments Demonstrate Enhanced Export Driven by Frontal Dynamics in the Chukchi Sea"

This repository contains the code used for data analysis and figure generation for the manuscript titled **"Sediment Trap Deployments Demonstrate Enhanced Export Driven by Frontal Dynamics in the Chukchi Sea."**

### Data

The data required for this processing pipeline can be found at the following link: [Stanford Digital Repository - Data](https://purl.stanford.edu/fy250ym8098).

**Citation:**
Lauer, J. A., van Dijken, G. L., Mills, M. M., Pickart, R. S., Arlen, L., Lim, S. M., Li, E., Payne, C. M., Proctor, C., Zhong, G., Prakash, M., & Arrigo, K. R. (2025). Data used in manuscript "Sediment Trap Deployments Demonstrate Enhanced Export Driven by Frontal Dynamics in the Chukchi Sea". *Stanford Digital Repository*. Available at [https://purl.stanford.edu/fy250ym8098](https://purl.stanford.edu/fy250ym8098). DOI: [10.25740/fy250ym8098](https://doi.org/10.25740/fy250ym8098).

### Usage Instructions

To run any of the analyses stored here, first download the dataset above and save to a folder titled `/data_directory` within this repository. Once the data_directory is present, navigate to the directory corresponding to the desired figure or table. Execute the scripts within the respective `/src` folders as-is. The generated figures will be saved in the corresponding `/plot` subdirectories.
